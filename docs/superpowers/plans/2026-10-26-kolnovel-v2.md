# Kolnovel V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add new extension `site:kolnovel-v2` for current starless theme, leaving `site:kolnovel` untouched.

**Architecture:** Single-file port `extensions/site.kolnovel2.js` copying V1 structure with only selector deltas; fixtures from live `/tmp/opencode/kol-*.html` samples; reuse `helpers.loadExtension/mockCtx/ok`.

**Tech Stack:** Vanilla JS sandboxed `registerExtension`, Vitest 5, `scripts/build-index.mjs`, Node 20 curl-verified live HTML.

**Spec:** Live evidence 2026-10-26 — `kol-search__item`, `kol-series-archive__item`, `kol-series-editorial__title/cover/genres/volumes`, `div#kol_content` survives, `<kol-comments wp-post-id wp-series-id>` replaces `entity-id`.

## Global Constraints

- New file `extensions/site.kolnovel2.js` only; never edit `extensions/site.kolnovel.js`.
- `id: 'site:kolnovel-v2'`, `name: 'كول نوفيل V2'`, `lang: 'ar'`, `version: '2.0.0'`, `apiVersion: 2`, `baseUrl: 'https://kolnovel.com'`.
- Same 13 public methods, same return shapes as V1; `rating/tags undefined` when missing, never fake defaults.
- Auth block byte-identical to V1 lines 15-25 plus `_cmtApi`.
- Sandbox-safe: no imports, no DOM parser, flat regexes + `_extractBlockContent` only for `#kol_content`.
- Bundle target ~60-65KB; `npm run build` must list `site:kolnovel-v2`.

## Review Focus

- Search with `·`-joined genres splitting on `·` not `,` — expect `['أكشن','غموض']` not single string.
- Novel page `<title>` contains `–`; title must come from `h1.kol-series-editorial__title` not `<title>`.
- Chapter list static HTML has empty `ul[data-kol-chapter-volume-content]`; must follow `?chapter_volume & chapter_page` pager links.
- `kol-comments` without `entity-id` must still resolve via `wp-post-id`; missing tag must return `{count:0}` not throw.
- Rating `★ 7.0` text must parse to `7.0` only when `0<rating<=5`, else `undefined`.
